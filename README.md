Este repositório contém todos os exercícios e projetos práticos desenvolvidos durante o Curso de JavaScript do canal Curso em Vídeo, ministrado pelo professor Gustavo Guanabara. Concluí o curso em 2024.

## Tecnologias Utilizadas
* JavaScript
* HTML5
* CSS3

## Estrutura do Repositório
Os exercícios estão organizados de acordo com os módulos do curso:
* **Módulo A:** Introdução
* **Módulo B:** Comandos Básicos
* **Módulo C:** Entendendo o DOM
* **Módulo D:** Condições em JS
* **Módulo E:** Repetições em JS
* **Módulo F:** Arrays, Funções e Objetos

## Projetos Práticos Desenvolvidos

Durante as aulas práticas, construí aplicações funcionais e interativas para consolidar a teoria:

* **Hora do Dia:** Interface dinâmica que altera cores e imagens do site conforme o horário do sistema operacional.
* **Verificador de Idade:** Formulário que processa o ano de nascimento e exibe imagens dinâmicas classificando a faixa etária e o gênero.
* **Tabuada e Super Contador:** Ferramentas criadas com foco no treinamento de lógicas de repetição (`while` e `for`).
* **Analisador de Números:** Sistema de formulário que recebe diversos valores em um Array e retorna um relatório com dados estatísticos (maior, menor, soma e média).
